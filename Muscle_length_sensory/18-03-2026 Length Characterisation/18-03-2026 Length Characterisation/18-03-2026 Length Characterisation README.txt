MetaData: 

MS/S = measurement Series
MPT/P = Measurement Point
PWMiR = PWM inlet valve Rise/inflation value
PWMeR = PWM outlet/exit valve Rise/inflation value
PWMiF = PWM inlet valve Fall/deflation value
PWMeF = PWM outlet/exit valve Fall/deflation value

DataFiles: 

MS = measurement Series
MPT = measurement point
t (s) = time since collection started (actually in ms)
PWMi = PWM inlet valve value
PWMe = PWM outlet/exit valve value
Pressure (Psi) = Internal muscle pressure 
LW (V) = Liquid wire sensor voltage change reading post amplification. Amplification ~ 1000x
Displacement (mm) = Linear potentiometer muscle displacement
